
# Análise de Desempenho de Lojas

Projeto de análise de dados voltado à tomada de decisão de negócio, com o objetivo de identificar qual unidade de uma rede de lojas apresenta o menor desempenho e deve ser vendida.



### Problema de Negócio

Uma rede de lojas precisa decidir qual unidade vender para viabilizar um novo investimento. A decisão deve ser baseada em dados de desempenho financeiro, vendas e satisfação dos clientes.



### Objetivo

Analisar o desempenho de quatro lojas considerando faturamento, volume de vendas, categorias de produtos, avaliações de clientes e custos logísticos.



### Principais Insights

- A Loja 4 apresentou o menor faturamento entre todas as unidades  
- A Loja 4 teve desempenho inferior em diversas categorias de produtos  
- A Loja 3 apresentou melhor avaliação média dos clientes  
- A Loja 1 apresentou alto faturamento, porém menor satisfação dos clientes  
- O menor custo de frete não foi suficiente para compensar o baixo desempenho da Loja 4  



### Solução Desenvolvida

- Tratamento e preparação dos dados  
- Criação de métricas de desempenho  
- Análise comparativa entre lojas  
- Visualização de dados para suporte à decisão  



### Análise de Dados

- Cálculo de faturamento total por loja  
- Comparação de categorias mais e menos vendidas  
- Avaliação da satisfação dos clientes  
- Análise de volume de vendas  
- Avaliação de custos logísticos (frete)  



### Impacto de Negócio

A análise permite:

- Identificar a loja com menor desempenho geral  
- Apoiar decisões estratégicas de investimento  
- Redirecionar recursos para unidades mais eficientes  
- Reduzir prejuízos operacionais  


### Conclusão

Com base nos dados analisados, a Loja 4 apresenta o pior desempenho geral e é a unidade com menor desempenho e, portanto, a principal candidata para venda.


### Recomendação

Recomenda-se a venda da Loja 4, permitindo concentrar recursos nas unidades com melhor desempenho, especialmente a Loja 3, que apresenta bom equilíbrio entre faturamento e satisfação dos clientes.
